# 源码阅读

## 建议代码阅读主线（按一次 forward 走）

**1. 预处理：`Qwen3TSProcessor` + `sp_encoding()`**  
`base_model/Config-Qwen3-8B/processing_qwen3_ts.py`：原始 `timeseries` → 均值中心化/缩放 → `[value, mask]` 交错 → padding。论文 §4.1 说的 value-preserving normalization 对应这里，不是 encoder 内部做的。

**2. TS Encoder：`TimeSeriesEmbedding`**  
`base_model/Config-Qwen3-8B/modeling_qwen3_ts.py`（`07_time_series_encoder.md` 已逐行梳理）：  
- 配置在 `config.json` 的 `ts` 段：`patch_size=8`、`num_layers=5`、`hidden_size=4096`、`use_position_embedding=true`  
- 有效长度 → `patch_cnt = ceil(valid_len / 8)` → 5 层 MLP → 每个 patch 一个 4096 维 token  
- 初始化：`initial_model.py` 只对 `ts_encoder` 做 Xavier（基座 Qwen 权重来自 HF，encoder 是新增模块）

**3. 与 LLM 融合：`_merge_input_ids_with_time_series_features()`**  
`modeling_qwen3_ts.py` 约 387–513 行（见 `08_embedding_merge.md`）：题面里 `<ts><ts/>` 占位符处的 text embedding 被 TS patch embedding **替换/扩展**，再进 `Qwen3Model`。这是「TS-LM」的核心，比 encoder 本身更值得细读。

**4. 三份镜像实现（对比读，不是重复读）**  
同一逻辑出现在三处，论文结构实验要确认「训练/推理/RL 是否一致」：  
- HF：`modeling_qwen3_ts.py`  
- vLLM 推理：`inference/vllm/chatts_vllm.py`  
- RL rollout：`src/EasyR1/verl/utils/chatts_vllm.py`

**5. 训练侧如何「动结构」**  
- Stage 1 对齐：`scripts/qwen3-8b/train_stage1.sh` + `ChatTSPlugin`（`src/llamafactory/data/mm_plugin.py`）+ 模板 `STReasoner-Align`  
- Stage 2 CoT：`train_stage1+2.sh`，脚本设 `--timeseries_sft_lr 1e-5`，意图给 `ts_encoder` 单独 LR（`src/llamafactory/model/model_utils/timeseries.py`）——**静态阅读有个待验证点**：`config.model_type` 是 `"qwen3"`，注册表却是 `"qwen3ts"`，专用 LR 可能未命中（见 `10_sft_training_flow.md`、`19_self_check.md`）  
- Stage 3 S-GRPO：`train_stage1+2+3_w_spatial.sh`；空间结构对照在 `src/EasyR1/verl/utils/dataset.py` 的 `remove_graph_structure()` + `ray_trainer.py` 的 spatial reward

## 论文里的「模型结构」在代码里对应什么

| 论文概念 | 代码位置 | 你读代码时要问的问题 |
|---------|---------|---------------------|
| 独立 TS encoder vs 文本/图像 prompt | `data/convert_to_text.py`、`convert_to_image.py` → `reasoning_text/`、`reasoning_image/` | 论文 Table 里 text/image baseline 的数据从哪来、训练脚本是否还用 `ChatTSPlugin` |
| patch + 5-layer MLP | `config.json` + `TimeSeriesEmbedding` | patch_size/num_layers 改 config 是否三处同步 |
| 三阶段训练 | `train_stage1*.sh` → `train_stage1+2*.sh` → `train_stage1+2+3_w_spatial.sh` | 每阶段哪些参数可训（全量 / LoRA / 仅 ts_encoder） |
| S-GRPO / 空间结构 | EasyR1 trainer + `str.py` reward | with/without graph 是**同一样本删 prompt 片段**，不是换数据集 |
| 模态消融（§5 Study of Time Series Modality） | 上面 text/image 变体 + 同一 RL 流程 | Dedicated encoder 的优势是结构+训练共同结果，不能单从推理脚本推断 |
