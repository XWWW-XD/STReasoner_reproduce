这是四题里最危险的一题：选项 D 在拓扑上几乎必选，所以「答案对」不代表「推理好」。如果按题干要求用 177–180 的时序证明顺序传播，这份 CoT 没有真正读窗口数据：既没有描述真实尖峰，也没有论证「2 先动、3 次之、4 再次之」。更像是背图结构模板做对选择题。这也解释了 correlation 任务的脆弱点：全量 ACC 中可能存在不少靠结构排除法得分、但没有精确对齐指定窗口的样本。

### Case 3：情境预测（forecasting，idx=9）

**题目要点。**
三节点小图，0/1 输入 2，2 反馈 1；语境是「最大日照加热期增强热传递」。题目给定历史窗 **30–35**，要求预测 Node 2 未来 3 步。

**真实数据。**
历史窗 index 30–35 中，Node 2 为 **19.64, 19.72, 19.90, 19.92, 19.79, 19.87**，整体缓升后末步略跌；Node 0 同期从 **18.10→18.98**，仍偏上升；Node 1 为 **19.40→19.71**，处于高位。Gold 未来三步是 **[19.86, 19.97, 20.05]**，第 3 步继续抬升。

**模型回答。**
模型的推理顺序比较完整：读图结构 → 读历史窗 → 看全序列趋势 → 结合「日照饱和」语境 → 判断 Node 2 继续上升但增速放缓。预测为 **[19.88, 19.90, 19.91]**，与论文 Table 9 的 **[19.88, 19.89, 19.90]** 非常接近，MAE≈0.077。

**质量判断。**
这是四题里叙事最完整、也最贴近论文 Appendix 的一题。它的逻辑是「上游一跌一稳、汇流点接近日饱和、未来小步缓升」，整体说得通。问题在历史读数有偏移：它写的 Node 2 窗内序列（19.74…19.87）比真值整体高约 0.1，Node 0 前段也有偏差。这说明它更像读到了一个形状相近但整体偏移的窗口。预测方向对，但幅度偏保守，尤其低估了 gold 第 3 步的 20.05。因此这题适合说明「推理链像论文」，但数值仍应以 ST-Test gold 为准，不能把 Appendix 预测当标准答案。

### 四题总体判断

四条 paper case 在全量 6144 跑批里都属于「正常卷」：回复较短、格式合规、未触顶；3 道选择题全对，forecasting MAE 也很小。但如果按「是否真正读懂题面时序」来判断，质量并不均匀。

- **Case 0 最好**：图结构、时序变化和选项排除形成闭环，和论文 Appendix 属于同一思路。
- **Case 3 次之**：推理链完整、预测接近论文展示值，但历史读数存在整体偏移，对 gold 第 3 步略低估。
- **Case 1 结论对、过程弱**：主要靠拓扑位置和选项语义答对，传播链细节多处与数据不符。
- **Case 2 最危险**：指定窗口的数值明显对不上，靠图结构排除法选对，不宜作为「数值也复现了」的证据。

因此，写 PPT 或周报时可以这样表述：Case 0/3 可以用于展示模型具备一定 STReasoner 风格的时空推理能力；Case 1/2 更适合用来提醒「答案正确不等于过程可靠，读数必须核查」。全量 benchmark 结论仍应以 `10-ST-TEST数据集效果.md` 为准，长尾退化可参考 `10.1-entity_idx838_6043tokens超长response样例.md`。
