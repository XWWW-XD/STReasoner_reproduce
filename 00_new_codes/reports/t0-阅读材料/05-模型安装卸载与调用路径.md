# 模型安装卸载与调用路径

## 0. 结论

本机建议只把大模型放在数据盘：

```text
/root/autodl-tmp/STReasoner_reproduce/base_model/
```

不要把大模型、checkpoint、HF cache 放到 `/root` 系统盘。之前系统盘爆满就是模型归档/缓存没有收尾导致。

当前策略：

- 需要 8B 推理时，安装 `STReasoner-8B` 到 `base_model/STReasoner-8B/`。
- 需要单卡 4B 三阶段训练复现时，安装 `Qwen3-4B-Instruct-2507` 到 `base_model/Qwen3-4B-Instruct-2507/`。
- 50G 数据盘上不建议长期同时保留 8B、4B、训练 checkpoint 和多个 cache。

## 1. 固定路径

| 模型 | 固定路径 | 用途 |
| --- | --- | --- |
| STReasoner-8B | `base_model/STReasoner-8B/` | 官方 8B 推理、ST-Test 复现 |
| Qwen3-4B-Instruct-2507 | `base_model/Qwen3-4B-Instruct-2507/` | 单卡小模型三阶段训练链路复现 |
| 4B TS config 模板 | `base_model/Config-Qwen3-4B-Instruct-2507/` | 复制到 4B 模型目录后再初始化 TS encoder |

## 2. 卸载 STReasoner-8B

适用场景：准备训练 4B，需要释放数据盘空间。

命令：

```bash
cd /root/autodl-tmp/STReasoner_reproduce

rm -rf base_model/STReasoner-8B
rm -rf /root/autodl-tmp/cache/huggingface/models--Time-HD-Anonymous--STReasoner-8B
rm -rf /root/autodl-tmp/cache/huggingface/.locks/models--Time-HD-Anonymous--STReasoner-8B

df -h /root/autodl-tmp
du -sh base_model /root/autodl-tmp/cache/huggingface 2>/dev/null || true
```

本轮执行结果：

- 删除前：数据盘约 `10G` 可用。
- 删除后：数据盘约 `27G` 可用。
- `base_model/STReasoner-8B/` 已删除。

注意：删除模型不会删除已生成的 `exp/` 推理结果。

## 3. 安装 STReasoner-8B

适用场景：需要重新跑官方 8B 推理。

推荐路径：

```text
base_model/STReasoner-8B/
```

下载时固定 cache 到数据盘：

```bash
cd /root/autodl-tmp/STReasoner_reproduce

export HF_HUB_DISABLE_XET=1
export HF_HOME=/root/autodl-tmp/cache/huggingface
export HF_HUB_CACHE=/root/autodl-tmp/cache/huggingface
export TRANSFORMERS_CACHE=/root/autodl-tmp/cache/huggingface

/root/autodl-tmp/conda/envs/str-py310/bin/huggingface-cli download \
  Time-HD-Anonymous/STReasoner-8B \
  --repo-type model \
  --local-dir /root/autodl-tmp/STReasoner_reproduce/base_model/STReasoner-8B \
  --max-workers 1
```

校验：

```bash

ls -lh base_model/STReasoner-8B/model-0000*-of-00004.safetensors
sha256sum base_model/STReasoner-8B/model-0000*-of-00004.safetensors
```

## 4. 安装 Qwen3-4B-Instruct-2507

适用场景：单卡 A100 小模型复现 STReasoner 三阶段训练链路。

下载：

```bash
cd /root/autodl-tmp/STReasoner_reproduce

export HF_HUB_DISABLE_XET=1
export HF_HOME=/root/autodl-tmp/cache/huggingface
export HF_HUB_CACHE=/root/autodl-tmp/cache/huggingface
export TRANSFORMERS_CACHE=/root/autodl-tmp/cache/huggingface

mkdir -p base_model/Qwen3-4B-Instruct-2507

/root/autodl-tmp/conda/envs/str-py310/bin/huggingface-cli download \
  Qwen/Qwen3-4B-Instruct-2507 \
  --repo-type model \
  --local-dir /root/autodl-tmp/STReasoner_reproduce/base_model/Qwen3-4B-Instruct-2507 \
  --max-workers 1
```

下载后复制 STReasoner TS config/code：

```bash
cp -a base_model/Config-Qwen3-4B-Instruct-2507/. \
  base_model/Qwen3-4B-Instruct-2507/
```

然后初始化 time-series encoder：

```bash
/root/autodl-tmp/conda/envs/str-py310/bin/python \
  initial_model.py \
  --model_path base_model/Qwen3-4B-Instruct-2507
```

重要经验：

- `Qwen/Qwen3-4B-Instruct-2507` 是 Qwen 官方 instruct 模型，不是 STReasoner 已训练好的 4B 成品。
- 复制 TS config 后，模型目录会变成可被 STReasoner 训练脚本识别的 Qwen3-TS 架构。
- `initial_model.py` 必须保持 fp16 保存，避免保存成 fp32 后目录膨胀到约 `17G`。

校验：

```bash
du -sh base_model/Qwen3-4B-Instruct-2507
ls -lh base_model/Qwen3-4B-Instruct-2507
grep -n '"model_type"' base_model/Qwen3-4B-Instruct-2507/config.json
```

调用示例：

```bash
--model_name_or_path ./base_model/Qwen3-4B-Instruct-2507
```
