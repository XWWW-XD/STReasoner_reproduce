## 1. 分类框架

| 类型 | 含义 | 本报告样例 |
| --- | --- | --- |
| **A. Persistent hard** | 三 run 均为 strict mismatch，复述数字/窗口稳定地错 | forecasting 19 |
| **B. Window drift** | mismatch 仍在，但窗口边界或写法随 run 变 | forecasting 179 |
| **C. Answer flip + mismatch drift** | final 选项翻转，且 thinking strict 列表出现/消失 | correlation 480 |
| **D. Mismatch intermittent, answer stable** | 三 run 答案相同，但 mismatch 标签时有时无 | correlation 503 |
| **E. Answer flip, no strict line** | 选项翻转，thinking 无 `Node k [a-b]:` 可比对行 | correlation 2 |
| **F. Singleton mismatch** | 仅单 run 进入 strict mismatch | entity 1175（run2） |
| **G. Strict triple-diverse** | 三 run 各为 A–D 且互异；几乎均 flip；**mismatch_run1=0** | correlation **119**（三全错）、**154**（D/C/B） |

## 2. Forecasting

### 2.1 idx 19 — Persistent hard（类型 A）

**题意**：预测 Node 0 未来 3 步；历史窗口 27–32。Gold：`[0.0, 1250.0, 0.0]`。

| run | `<answer>` | Node 1 [27-32] 复述（strict 行） | MAE（约） |
| --- | --- | --- | --- |
| run1 | `[1210, 1330, 1450]` | 1550, 188.64, … max diff **1143** | 高 |
| run2 | `[709.52, 744.36, 777.21]` | 390.10, 486.29, … | 高 |
| run3 | `[725, 765, 795]` | 390.10, 486.29, … | 高 |

**机制**：Node 1 窗口在 run1 出现 **量级幻觉**（1550 填充）；run2/3 同一 Node 0 行数值接近但 **预测序列仍随 run 变**（MAE Δ>1）。说明 **persistent 复述错 ≠ persistent 预测**——两层独立波动。

### 2.2 idx 179 — Window drift（类型 B）

**题意**：预测 Node 1 未来 3 步；历史窗口 62–67。Gold：`[0.0, 349.77, 0.0]`。

| run | `<answer>` | 关键 strict 行 |
| --- | --- | --- |
| run1 | `[131.5, 136.8, 142.0]` | `Node 0 [62-67]: 29.50, 31.89, …` |
| run2 | `[132.50, 138.20, 143.50]` | `Node 0 [62-67]: 29.72, 48.89, …`（数字变） |
| run3 | `[320, 315, 310]` | `Node 0 [61-66]: …`（**窗口偏移 1 步**） |

**机制**：run3 窗口 `[61-66]` 仍 mismatch，但 **边界漂移** 导致 run1/2 与 run3 的 strict 标签不可直接逐字对比；run3 预测 **跳变**（~320 vs ~132），属 answer 层大波动 + 复述层窗口 drift 叠加。

## 3. Correlation

### 3.1 idx 503 — Mismatch intermittent, answer stable（类型 D）

**题意**：Node 0 与 Node 4 在 steps 68–78 的关系。Gold：**B**。

| run | `<answer>` | strict mismatch？ |
| --- | --- | --- |
| run1 | B（对） | **是**（Node 4 常数 ~370 vs raw 峰值 3942） |
| run2 | B（对） | **是** |
| run3 | B（对） | **否**（未进 mismatch 集） |

**机制**：三 run **答案全对且相同**，但 run3 thinking 可能改用 `(steps 68-78):` 等非 strict 格式、或未写可解析数值列表 → **标签 drift 不伴随 answer flip**。这是 RQ3「没写出列表 vs 数字变了」中 **格式/抽取边界** 的典型案例。

run1 复述摘录（artifact）：Node 4 `(steps 68-78): 370.16, 370.19, …` — 相对 raw **几乎常数填充**，却仍选对 B（mismatch 组更常答对的一例）。

### 3.2 idx 480 — Answer flip + mismatch drift（类型 C）

**题意**：steps 68–74 影响。Gold：**C**。

| run | `<answer>` | 对错 | strict 行示例 |
| --- | --- | --- | --- |
| run1 | C | 对 | `Node 0 [67-73]: 221.26, 491.26, …` |
| run2 | C | 对 | `Node 0 [67-73]: 219.26, 401.16, …`（数字变） |
| run3 | **A** | **错** | **无** strict `Node k [a-b]:` 行 |

**机制**：run1/2 有 strict 列表且答案稳定；run3 **同时** 丢掉可比对行 **且** 选项翻成 A——thinking 与 answer **同向恶化**，但仍是关联而非 evaluate 因果（evaluate 不读 thinking）。

### 3.3 idx 2 — Answer flip, no strict line（类型 E）

Gold：**B**。

| run | `<answer>` | 对错 |
| --- | --- | --- |
| run1 | C | 错 |
| run2 | C | 错 |
| run3 | **B** | **对** |

**机制**：`flip_patterns` 中的 **WWR** 模式（两错一对）；thinking 用自然语言描述 steps 15–19，**无 strict 窗口行** → 不在 mismatch 集，却占 flip 样本中的 **多数**（见主报告 §9.3：70% flip 从未 mismatch）。

## 4. Entity

### 4.1 idx 1175 — Singleton mismatch（类型 F）

| run | `<answer>` | strict mismatch |
| --- | --- | --- |
| run1 | D | 否 |
| run2 | D | **是**（4 窗口，run2 独有） |
| run3 | D | 否 |

**机制**：entity 在 strict 口径下几乎无 mismatch（run1=0）；1175 是 **单次 run 的抽取/写法偶发** 进入规则，**不改变** 三 run 相同且正确的 final answer——说明 strict 标签对 entity 的 **信噪比极低**。

---

## 5. 跨案例小结

1. **Answer 翻转 ≠ mismatch 翻转**：503（D）、2（E）与主报告 §9.3 的 70% 数字一致。
2. **Forecasting 两层波动**：19 显示 persistent 复述错与 run 间预测变幅可并存；179 显示窗口边界也 drift。
3. **Correlation mismatch 可「写错仍选对」**：503 常数填充仍 B；与 §5.2「mismatch 组更常答对」一致。
4. **Evaluate 隔离 thinking**：上述所有 case 的官方计分 **仅看 `<answer>`**；thinking 变化只影响我们对「模型是否真读到了序列」的判断，不直接进入 metrics。
