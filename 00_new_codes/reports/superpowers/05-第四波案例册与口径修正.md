## 1. 重要修正：「67 题 A/B/C 全不同」需拆口径

[`triple_diverse_cross.json`](artifacts/triple_diverse_cross.json)：

| task | loose（evaluate 抽出的 pred 字符串三不同） | **strict（三 run 各为单字母 A–D 且互异）** | 其中 loose 但非 strict |
| --- | ---: | ---: | ---: |
| correlation | 67 | **18** | **49** |
| entity | 40 | **31** | **9** |

**解读**

- wave3 报告的 67/40 用的是 **loose** 口径（`_normalize_choice(extracted_pred)` 三值不同）。
- **strict 单字母三不同** 仅 **18 + 31** 题——才是「三 run 真的选了三个不同选项」。
- 其余 **49** 题 correlation 属于 **parser/格式异常** 或 **非单字母 extracted 串**（如 run2 无 `<answer>`、extracted 串异常），不应称为「A/B/C 全不同」。
- 本波分析脚本初版对 **已抽取 pred 再套 `<answer>` 正则**，曾误报 strict=0；已修复为 `extract_answer(pred) or pred.strip()`。

**补分析**：Superpowers 迭代的价值之一，就是 **后一波用更严口径推翻前一波 headline**——此处即例。
