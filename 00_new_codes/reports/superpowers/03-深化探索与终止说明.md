## 1. Persistent Core 错误分型

对 **三 run 均为 strict mismatch** 的样本，取三 run 中 `max_abs_diff` 最大的窗口，规则分类（启发式，非 ground truth）。

### 1.1 Forecasting（n=104）

| 类型 | 数量 | 占比 | 含义（启发式） |
| --- | ---: | ---: | --- |
| **local_drift** | 65 | 62.5% | 均值差中等、max diff <80 |
| other_large_error | 25 | 24.0% | 大偏差但不满足更细规则 |
| magnitude_offset | 7 | 6.7% | 复述量级整体偏移 |
| constant_fill | 5 | 4.8% | 近乎常数填充 |
| spike_hallucination | 2 | 1.9% | 单点极端 spike（含 idx 19） |

严重度：88 题 max diff ≤100；10 题 100–500；**6 题 >500**（含 19、116、25、179）。

### 1.2 Correlation（n=190）

| 类型 | 数量 | 占比 |
| --- | ---: | ---: |
| **constant_fill** | 66 | 34.7% |
| **local_drift** | 66 | 34.7% |
| other_large_error | 46 | 24.2% |
| magnitude_offset | 11 | 5.8% |
| spike_hallucination | 1 | 0.5% |

严重度：97 题 ≤100；72 题 100–500；**21 题 >500**。

**对比**：correlation persistent core **更常** 出现常数填充（34.7% vs forecasting 4.8%），与 503 类案例一致；forecasting 以 **局部数值漂移** 为主。

## 2. Persistent 集上的「两层稳定性」

### 2.1 Final answer（[`persistent_answer_stability.json`](artifacts/persistent_answer_stability.json)）

| task | 三 run 解析 answer 全同 | 对错标签全同 |
| --- | ---: | ---: |
| **correlation** (190) | **158** (83.2%) | **165** (86.8%) |
| **forecasting** (104) | **0** | **103** (99.0%) |

**解读**：

- Correlation：**persistent 复述错** 仍可能 **三 run 选同一选项**（158 题）——复述与选项再次解耦。
- Forecasting：数值预测 **104/104** 三 run 字符串不同（T=0.2），但 strict「全对」几乎不存在（103 题三 run 同为错）。

### 2.2 Mismatch 窗口集合（[`cross_run_window_jaccard.json`](artifacts/cross_run_window_jaccard.json)）

| task | 三 run mismatch 窗口集合完全一致 | 平均 pairwise Jaccard |
| --- | ---: | ---: |
| forecasting | 71/104 (**68.3%**) | 0.846 |
| correlation | 98/190 (**51.6%**) | 0.786 |

Persistent **标签** 稳定，但 correlation 有一半样本 **具体错窗集合** 仍随 run 变——与 §5.3 drift 案例一致。

## 3. Forecasting：复述 persistent 能否预测 MAE 波动？

[`forecasting_mae_volatility.json`](artifacts/forecasting_mae_volatility.json)（三 run MAE range >1 的比例）：

| 子集 | n | MAE range >1 |
| --- | ---: | ---: |
| persistent mismatch（三 run 交集） | 104 | **55.8%** |
| 非 persistent 但曾 mismatch | 73 | 65.8% |
| 从未 mismatch | 103 | **58.3%** |

**结论**：persistent 复述错 **并未** 带来更高的 answer 数值波动；三档比例接近。MAE run 间变化 **不能** 用「是否 persistent mismatch」简单区分——与主报告 §9.3「两通道独立」一致。

## 4. Entity / Etiological：非 strict 叙述（run1）

[`loose_numeric_mentions.json`](artifacts/loose_numeric_mentions.json)：

| task | loose 数值叙述（无 strict 行） | 几乎无数值叙述 | strict mismatch |
| --- | ---: | ---: | ---: |
| entity (1194) | **591** (49.5%) | 603 | **0** |
| etiological (207) | **142** (68.6%) | 65 | **0** |

**解读**：半数 entity、近七成 etiological 在 thinking 里 **写了 Node+数字**，但 **strict 规则抽不出可比对窗口**——当前 mismatch 口径 **系统性低估** 这两任务的「口头读数」。要进一步量化需 **新口径**（放宽 regex 或人工标注），现有 artifact 无法继续深入。

### 训练结构（只读对照）

`SupervisedDatasetProcessor`（`src/llamafactory/data/processor/supervised.py`）：prompt 段 `IGNORE_INDEX`，**response 段（含 thinking+answer 全文）参与 CE loss**；timeseries 经 mm_plugin 嵌入，**无**「复述数值≈raw」的单独 loss。

→ 与 inference 侧「可瞎写 thinking、只看 answer 计分」**结构相容**；仍非训练 ablation 因果证明。

## 8. 补分析摘要

- **Correlation persistent core 约 35% 常数填充**，解释「复述离谱但仍选对」的 mass 来源之一。
- **Forecasting persistent core 以 local_drift 为主**， catastrophic 仅 6 题，可优先人工看这 6 题。
- **Persistent mismatch 不放大 MAE 波动**——复述 persistent ≠ 预测更不稳。
- **Entity/etiological 有大量 loose 数值叙述但 strict mismatch≈0**——是当前方法论硬边界。
