大文件与 cache 一律放数据盘；`initial_model.py` 保存须 fp16（否则 4B 目录膨胀到 ~17G）。详见报告 15、`guides/运行日志清理.md`、可复用条目见 `guides/修改文件必读规则.md` §单卡小模型训练经验。

### 4.2 LoRA 与训练栈

- 用 **bf16 + `--flash_attn fa2`**；日志须见 FlashAttention-2，不要 SDPA。
- 禁止 `lora_target=all`（会误匹配 `Qwen3DecoderLayer`）；显式写 Qwen 线性层，由 time-series patch 追加 `ts_encoder.mlp.*`。
- 禁止 `--additional_target ts_encoder`（与 mlp LoRA 冲突，PEFT 加载 KeyError）；旧版 10/100 step 产物因此作废。
- `bitsandbytes==0.43.1` 在当前 triton 下会 `triton.ops` 报错 → 升到 **0.45.2**。
- conda 脚本须把 env `bin` 进 `PATH`，否则 DeepSpeed 编译 CPUAdam 找不到 ninja。
- 须 `WANDB_DISABLED=true` 且 `--report_to none`，否则无人值守会卡 API key。
- fp16 曾出现 `grad_norm=nan`、`lora_B` 仍零的 **假成功** → 改 bf16 后才是真更新。

### 4.3 如何判断「真训上了」

不能只看进程退出码。至少查：`trainer_state.json` 有 step/loss；`adapter_model.bin` 里 **lora_B 全非零**；日志有 `Applied SFT learning rate … to … time-series encoder`；`PeftModel.from_pretrained` 能加载。训练集小探针（6/30/40 条）只能看形态变化，**不能**当 ST-Test 或论文效果。

### 4.4 adapter 接续口径

`save_only_model` 下用 `--adapter_name_or_path` 开新 run，只继承权重，**不继承** optimizer / lr schedule / global step，不要写成「严格连续训练」。若需真 resume，须保存 `optimizer.pt`、`scheduler.pt`、`rng_state.pth`、`trainer_state.json` 并用 `resume_from_checkpoint`（本实验仅在 2000 段试过，后续 2500 已取消）。
