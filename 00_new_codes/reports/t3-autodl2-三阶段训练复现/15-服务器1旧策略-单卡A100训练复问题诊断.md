# 服务器1旧策略训练复现结论

日期：2026-06-04  
环境：AutoDL 服务器1，单卡 A100-PCIE-40GB  
模型：Qwen3-4B-Instruct-2507  
任务：Stage 1，4B 全参微调 10-step smoke  
策略：DeepSpeed ZeRO-3 + CPU offload all（`ds_config_3_offload_all.json`）  
脚本：`single_a100_qwen3_4b_stage1_smoke.sh`（`experiments/scripts/`）

---

## 一、结论

服务器1上，**4B 全参微调 + ZeRO-3 CPU offload all 不可行**。

失败原因不是 GPU 显存，而是 **CPU / 容器内存上限**。

卡点：进程在初始化 **optimizer states** 时被 SIGKILL（-9），尚未进入实际训练 step。


| 关键数据                                       | 数值                    |
| ------------------------------------------ | --------------------- |
| GPU                                        | A100-PCIE-40GB（未成为瓶颈） |
| cgroup `memory.max`                        | 约 **77.3GB**          |
| CPU virtual memory                         | 约 **78.48GB**         |
| `output/single_a100_qwen3_4b_stage1_smoke` | **0**（无 checkpoint）   |
| `DEEPSPEED_TIMEOUT` 提到 1800                | 仍 -9（非超时）             |


**不建议在服务器1上重复该配置。**

## 三、失败过程

### 3.1 依赖不兼容：triton 不兼容

```text
ModuleNotFoundError: No module named 'triton.ops'
```

`bitsandbytes==0.43.1` 与当时 torch/triton 不兼容 → 升级到 **0.45.2** 后通过。

### 3.2 编译环境 PATH：ninja

```text
RuntimeError: Ninja is required to load C++ extensions
```

`ninja` 已装在 conda env，但 smoke 脚本 **PATH 未含 env/bin** → 脚本加入 `PATH`；并设 `TORCH_EXTENSIONS_DIR` 到数据盘，CPUAdam 编译成功。

### 3.3 容器内存顶满

```text
SIGKILL -9
```

失败断点在 `Before initializing optimizer states` 之后；CPU vmem 约 **78.48GB**，超过 `memory.max` 约 **77.3GB**。


| 现象                        | 常见含义     |
| ------------------------- | -------- |
| CUDA OOM                  | GPU 显存不够 |
| 子进程 -9、CPU vmem 贴近 cgroup | 主机内存顶满   |


本次属于后者。

## 四、保留经验

开训前：

```bash
df -h / /root/autodl-tmp
du -sh /root/model_archive /root/.cache /root/autodl-tmp/cache
cat /sys/fs/cgroup/memory.max
```

smoke 脚本固定：

```bash
export PATH="/root/autodl-tmp/conda/envs/str-py310/bin:${PATH}"
export HF_HOME=/root/autodl-tmp/cache/huggingface
export HF_HUB_CACHE=/root/autodl-tmp/cache/huggingface
export TRANSFORMERS_CACHE=/root/autodl-tmp/cache/huggingface
export TORCH_EXTENSIONS_DIR=/root/autodl-tmp/cache/torch_extensions
export TRITON_CACHE_DIR=/root/autodl-tmp/cache/triton
```

磁盘（调查时 2026-06-04）：系统盘 ~10%；数据盘 ~64%（剩 ~19G）；模型 ~8.3G、ST-Bench ~3.8G、HF cache ~5.3G。大文件与 cache 放数据盘；勿留 `/root/model_archive` 副本；`initial_model.py` 保存须 fp16。

其它：HF 下载卡住可 `HF_HUB_DISABLE_XET=1`；下载后用 `model_check.py` 验分片；Stage 1 前确认 `alignment_train.jsonl` 已下载。
