# 分析入口说明

> 三层分工：**scripts = 实验跑数**；**tools = 只读小工具/图表**；**superpowers/_analysis = 波次批算**。

## 目录对照

| 目录 | 含义 | 示例 |
| --- | --- | --- |
| `…/experiments/scripts/` | GPU/推理/训练/评测脚本 | `repro_autodl/experiments/scripts/stage2_*.py`；存档 `repro_kaggle/.../stage1_script/` |
| `00_new_codes/tools/` | 只读分析、表格、画图 | `json_to_md_table.py`、`columns.py`、`tools/mlp_encoder_focused_analysis/*.py` |
| `reports/superpowers/_analysis/` | Superpowers batch compute、`verify_reports.py` | `compute_*.py`、`run_all_computes.py` |

## 产物放哪

```text
exp/ 或 exp_STReasoner-8B/     ← 正式推理输出（generated_answer.json）
reports/artifacts/<任务>/      ← tools 跑出的 JSON/附件（见 artifacts/README.md）
reports/superpowers/artifacts/ ← wave ledger（稳定性、registry 等）
```
