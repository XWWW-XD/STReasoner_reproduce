# 运行日志（`.log`）清理

修改：2026-06-09

本文件路径：`00_new_codes/guides/运行日志清理.md`

## 规则

- **删除对象**：本仓库内所有 `*.log` 运行日志。
- **不删除**：`*.md`（含 `00_new_codes/reports/` 下的任务日志与报告）。
- **保留期**：**30 天**。超过 30 天的 `.log` **全部删除**。

## 常见路径

| 路径 | 示例 |
| --- | --- |
| `00_new_codes/repro_autodl/experiments/logs/` | smoke、LoRA 训练重试日志 |
| `00_new_codes/repro_autodl/experiments/` | `env_check_*.log`、`stbench_download_*.log` |
| `00_new_codes/repro_autodl/experiments/results/` | `run.log`、`paper_cases_run.log`、stage2.4 子目录 `logs/*.log` |
| `exp/` | `run.log`、`evaluate.log` |
| `00_new_codes/reports/artifacts/` | 分析脚本产出的 `*.log`（若有） |

## 判断「超过 30 天」

1. 优先看文件修改时间（`mtime`）。
2. 文件名含 `YYYYMMDD` 时间戳时，若与 mtime 矛盾，以 **更早** 日期为准。

## 与 git / 正式产物

- `.gitignore` 已忽略 `*.log`；若曾被误 `git add`，清理时一并 `git rm`。
- **不因删 log 而删**：`generated_answer.json`、`evaluation_metrics.json`、`summary.json`、`predictions.jsonl` 等。
- 排障结论、关键数值应写在 `00_new_codes/reports/*.md`；删 `.log` 后以报告为准。

## 清理命令（在仓库根目录执行）

```bash
# 先列出
find . -type f -name '*.log' -mtime +30 ! -path './.git/*'

# 确认后删除
find . -type f -name '*.log' -mtime +30 ! -path './.git/*' -delete
```
